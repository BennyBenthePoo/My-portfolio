MY PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the new_portfolio folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension.

FILES
- index.html: website content and sections
- css/style.css: colors, layout, responsive design
- js/script.js: mobile navigation and current year
- images/profile.png: profile photo used in the hero section

PERSONALIZE YOUR WEBSITE
- Change the page title and hero/about text in index.html.
- Replace images/profile.png with your own photo (keep the filename the same, or update the image path in index.html).
- Replace hello@example.com in index.html with your real email address.
- Update the sample project descriptions and skills to match your actual experience.
- Update the project cards with links to your actual project files or GitHub repositories.

This is a static HTML/CSS/JavaScript website. The contact button opens the visitor's email application; it does not send messages through a backend.
